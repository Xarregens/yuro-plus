# Tests (navigateur simulé)

Mêmes prérequis que le dépôt kyara-plus : Node 18+, `npm install playwright`, `npx playwright install chromium`.

Lancer depuis ce dossier : `node yuro.cjs ../yuroPlus.user.js`

| Script | Ce qu'il vérifie |
| --- | --- |
| `farm.cjs` | Relance du farm : clic immédiat par défaut (sans message), retentatives puis arrêt, mode secours 12 s (`relanceRapide(false)`), rien si toggle OFF ou relance coupée, réglages mémorisés. |
| `raid.cjs` | Raids : Replay auto du site allumé, à la victoire « ↻ Rejouer » [data-raid-level] cliqué en ~0,6 s (le site attend ~2 s) ; rien si Replay auto éteint, défaite, écran déjà en train de partir, ni sur le « Rejouer » du château. |
| `tower.cjs` | Château de l'infini : bouton « Suivant auto » monté et mémorisé, chambre suivante à la victoire, rien à la défaite, compteur dédié. |
| `hw.cjs` | Halloween : « Rejouer auto » monté (éteint par défaut), « Affronter à nouveau » cliqué à la victoire une fois allumé, jamais la citrouille / la défaite / le bandeau compact, mémorisé ; bandeau redessiné sans clignotement ; série V · D · bonbons comptée et remise à zéro. |
| `boosters.cjs` | (Récapitulatif simulé qui montre d'abord les cartes d'avant pendant 150 ms, comme le vrai site : ni rare en double ni rare manquée, bilan détaillé par rareté ; la 0.11.7 y échoue.) Boutique de boosters : « Ouverture auto » (éteinte par défaut, jamais mémorisée) remet la puce Gratuit si le joueur a pris Ki, choisit ×10, ouvre les 2 gratuits puis les 8 de quête (source « reward » comme sur le vrai site ; l'ancienne 0.11.1 échoue ici) (aussi quand le site ne passe pas seul aux Quêtes : source épuisée gardée, bouton grisé) (déchirer → « Tout passer » → rares lues, page 2 comprise → « Ouvrir encore »), s'arrête quand il ne reste que du ki ; JAMAIS de clic sur « Ouvrir » payé en ki, une jaquette ou « Rouvrir » (contre-épreuve : un script qui accepterait le ki échoue) ; mode éclair pendant la séance seulement ; journal des rares (aussi en manuel), panneau en fin de séance ; booster qui ignore les clics 0,7 s → déchiré en moins de 1,5 s (la 0.11.2 attendait 5 s). |
| `marche.cjs` | Marché (Vendre) : puce « Doublons » montée après les puces de rareté (éteinte à chaque arrivée sur Vendre, pas mémorisée) ; allumée, masque les cartes à ×1, clique « Afficher plus » jusqu'au bout (300 cartes en moins d'une seconde), compte les doublons, survit au redessin du site sans manquer à une seule image, absente de l'onglet Acheter où rien n'est cliqué. Puce « Prix en ligne » : tri décroissant par prix le moins cher en ligne des AUTRES joueurs (ni mes annonces, ni échanges, ni annonces vendues), puis par cote ; étiquettes de prix ; combinable avec Doublons ; aucune image mal triée quand le site redessine la grille (clic sur une carte, retour à 24 cartes après une vente ; la 0.12.0 en montre 9) ; données via marketUI.data ou, sans elle, via la réponse /api/market lue au passage ; jamais de clic sur une carte ni sur « Publier ». |
| `boite.cjs` | Boîte noire : page figée 11 s pendant un rejeu onglet caché → rapport (rappel en cours, suite des derniers rappels avec leur type, code du rappel long, derniers états, heure de reprise) ; blocage au retour au premier plan hors de notre rejeu : retour daté, fonction, fichier et passage de code nommés par la mesure du navigateur ; code de la fonction en cours connu dès son lancement ; disjoncteur : au 3e blocage de plus d'une seconde onglet caché, arrière-plan en pause avec message (pas au 2e), relançable téléchargé par `yuroDiag.boiteNoire()`, message au chargement suivant une seule fois, aucune fausse alerte ; frein anti ping-pong quand le site retire nos boutons aussitôt ajoutés (contre-épreuve : sans frein, la page se fige). |
| `animations.cjs` | Onglet caché : les animations figées (aucune ne se joue onglet caché) dont la durée est écoulée sont terminées par le script et le site reçoit `animationend` — 300 effets simulés retirés, boucle intacte, élément restant figé sur son état final ; 200 effets animés en JavaScript retirés grâce au « finish » envoyé par le script (la 0.11.6 n'en envoie aucun) ; rien quand l'onglet est visible ou l'arrière-plan coupé (la 0.11.3 échoue : effets empilés, cause des pages figées au retour). |
| `fond.cjs` | Arrière-plan : onglet vu visible par le site, visibilitychange retenu, minuteries et animations rejouées par le worker, arrierePlan(false) mémorisé. |
| `fincombat.cjs` | `yuroDiag.finCombat()` : ignore l'écran de fin déjà affiché, reconnaît le suivant même renommé (bouton « Recommencer »), télécharge sa photo (yuro-diag-fin) puis l'enregistrement de la relance (yuro-diag-relance, mutations et requête de combat suivant) ; ne clique rien. |
| `yuro.cjs` | Commandes `yuroDiag` : requêtes notées en continu (masquage des e-mails et clés sensibles), enregistrement des clics et mutations, photo immédiate, WebSocket notée, téléchargement. |
